# IT Rescue Mission

*Java Console-Based IT Quiz Game*

## About the Project
IT Rescue Mission is a Java console-based quiz game designed to test and improve the player's knowledge of Information Technology through fun and interactive questions.

## Features
- Player registration and profiles
- Three difficulty levels: Easy, Medium, and Hard
- Randomized quiz questions
- Three lives per game
- Points and bonus scoring system
- Leaderboard
- Game history and player statistics
- Achievement badges

## Technologies Used
- Java
- Online Java Compiler
- GitHub

## How to Run
1. Open Main.java.
2. Copy the source code.
3. Paste it into a Java compiler.
4. Run the program.
5. Follow the instructions displayed on the console.

## Project Purpose
This project was created as a programming activity for CC102 to apply basic and intermediate Java programming concepts.
